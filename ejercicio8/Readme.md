# 🎮 Torneo de Videojuegos

Proyecto desarrollado en **Python** para el Instituto Tecnológico de Ensenada 🏫 utilizando **Programación Orientada a Objetos (POO)** y el concepto de **Herencia**.

---

# 📌 Descripción

El sistema permite registrar participantes para un torneo de videojuegos, diferenciando entre:

- 🎮 Competidores
- 👀 Observadores

Ambos tipos heredan características de una clase base llamada `Jugador`.

Este proyecto fue creado para practicar:

- Herencia
- Sobreescritura de métodos
- Uso de `super()`
- Modularización en Python
- Programación Orientada a Objetos
